# Vision — strange-galaxy

Arbeitstitel. Status: DRAFT. Game Design bewusst offen.

## Idee

Ein Open-Source-Spiel, das die Community gemeinsam baut. Ein Experiment: wie weit kommt ein Spiel, wenn Umsetzung durch AI kaum noch Hürde ist und Menschen Richtung und Ideen liefern?

## Rahmen

- Engine: Godot
- Lizenz: MIT, komplett offen
- Setting: seltsame Galaxie, bewusst goofy, Grafik egal
- Muss auf schwacher Hardware laufen
- Kleine Gruppen spielen zusammen (Co-op)
- Von Spielern erzeugte Inhalte sind willkommen, auch AI-generiert

## Wie entwickelt wird

- Über das Framework `community-gate`: Vorschläge, Abstimmungen, Feature-Branches, ein PR pro Feature
- Community entscheidet über Features, nicht über Sicherheit: Code-Gates und Review sind nicht verhandelbar
- Release, wenn die Community dafür stimmt
- Der Initiator kann das Experiment jederzeit stoppen

## Orientierung (nur Inspiration, keine Assets, keine Namen)

- Star Citizen: das Spiel, das nie fertig wird
- Schedule 1, Valheim: simpel, goofy, läuft überall
- No Man's Sky: Start in einem System

## Nicht-Ziele

- Kein garantiert gutes Spiel. Scheitern ist ein gültiges Ergebnis.
- Keine fremden Marken, Assets oder Reverse-Engineering fremder Spiele.
