# Roadmap — EXO-1

Status: living. Milestones are coarse on purpose; details get worked out when a milestone starts. The order was approved by the initiator on 2026-10-08 (`DECISIONS.md`, "Roadmap order"). The work is planned in GitHub milestones of the code repo `exo-1` (map issue #18); this file is the short picture. Counts below are from GitHub on 2026-10-09 and age quickly.

Related: `VISION.md` (what and why), `CORE-LOOP.md` (loop, pillars, MVP scope), `DECISIONS.md` (decided, open, parked), `FEASIBILITY.md` (research of 2026-10-03, partly historic).
