# EXO-1 concept

Vision, decisions, spike reports and research for EXO-1 (working title): a goofy co-op space game in a strange galaxy, written in Rust with Bevy. No code lives here; the code is in the repo `exo-1`.

## Read in this order

1. `docs/VISION.md`: what the game is and why.
2. `docs/DECISIONS.md`: only what the initiator decided, quoted in their words with a date, grouped by topic.
3. `docs/CORE-LOOP.md` and `docs/ROADMAP.md`: the loop, the scope, the milestones A to E and P.
4. `docs/LEARNINGS.md`: read before running the game, changing git state or starting a spike.

## What lives where

- `docs/PROGRESS.md`: dated log and an overview of all spikes.
- `docs/SPIKE-*-REPORT.md`: results of the throwaway experiments. Their briefs are in `docs/archive/`.
- `docs/archive/`: finished briefs, the night run of milestone C, the Godot-era roadmap. Kept for the record, not maintained.
- `docs/research/`: our own research notes (loop, planets, flight feel, Star Citizen, No Man's Sky, design tools, city building, place authoring).
- `docs/FEASIBILITY.md`, `docs/REFERENCE-NOTES.md`, `docs/SOURCES-TO-CHECK.md`: early research (FEASIBILITY is historic).
- `research/`: third-party material, never to be published: `sources/` holds saved copies of articles and transcripts; `local/` holds unpacked game records and is gitignored.

## Working here

Rules for agents live in the code repo's `AGENTS.md`, see `AGENTS.md` here. New contributor: clone `exo-1` next to this repo and run the skill `exo-onboarding` there.
